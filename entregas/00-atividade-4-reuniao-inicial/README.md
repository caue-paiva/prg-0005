# Atividade 4 — Ata da primeira reunião

**Trabalho preenchido pela equipe:** [ata da Collabora.AI](ata-collabora-ai.pdf). Este arquivo antecede as entregas do módulo 2; **não é a Entrega 4** do percurso de Design Thinking.

A ata registra os interesses iniciais da equipe, duas ideias discutidas e a escolha preliminar de uma lousa colaborativa de estudos com IA. Os próximos passos previstos eram pesquisar propostas semelhantes, pensar no modelo de negócios e ouvir outras pessoas.

Na [Entrega 1](../01-delimitacao-do-problema/Entrega_1_Collabora.AI.pdf), a equipe retomou essa ideia e recuou para formular o problema de estudo em grupo no começo da graduação. Ao preparar as entregas seguintes, use a ata para entender a origem do projeto; trate a ideia de solução como proposta inicial, sujeita aos achados das entrevistas.
